# CLAUDE.md

Este é um adaptador para Claude Code. A fonte canônica é `AGENTS.md`, seguida por `docs/*`.

Antes de implementar:

1. leia `AGENTS.md`;
2. leia `docs/README.md` e os documentos nucleares, não leia `docs/site`;
3. confirme que a Fase 0 foi aprovada e a issue está em andamento;
4. não resolva ambiguidades de `docs/requirements.md` por inferência.

Ao concluir, execute os checks de `docs/testing.md` e atualize `docs/issues.md`, `docs/implementation-plan.md` e `docs/deployment-log.md`.

Não remova este arquivo sem aprovação humana explícita.
